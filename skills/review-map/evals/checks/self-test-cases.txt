# The checks, checked. Every fragment in golden/ plants exactly one defect, and a row here says
# what a check is supposed to say about it.
#
#   check | golden fragment | expected exit | a substring the output must contain | extra args
#
# Expected exit is 0 or 1. A WARN is not a failure, so a fragment that only warns expects 0 and
# is pinned by its substring instead.
#
# The fifth column is optional and exists for a check that needs more than a fragment. @GOLD@
# expands to the golden directory, so searches can be handed a repository to search, and @REPO@
# plus @REPO_BASE@ to the two-commit git repository golden/links-repo.sh builds, which is what
# link-form needs to ask git which files GitHub renders. Those two are the checks whose rule is a
# relation between the page and a repository, and a check that can only SKIP here is exactly what
# this file exists to prevent. The column also carries --level for a fragment produced at the
# skill's brief detail level, --page for a rule that only holds on a whole page, and an
# unresolvable ref for the rules that ask git a question and must not read a failure as an answer.
#
# A DATA FILE, not a heredoc, because two readers need it: self_test.rb asserts these verdicts,
# and frozen.rb replays the same rows so the frozen corpus covers --repo, --base, --level and the
# fixture repository, none of which its fixture sweep ever passes. It was a heredoc parsed with
# `while IFS='|' read`, which needed a sed trim per column and a deliberately unquoted fifth field.
