archived_at_changed? vs saved_change_to_archived_at?

Each attribute carries two questions, and they are true at different moments: one compares memory against the row that was loaded and is true before the save, the other reports what the save just wrote and is true only after it.

The callback at app/models/project.rb:4 runs after the write, so the second form is the one it has to ask.
In practice 
post = Post.find(1)
post.title = "new"
post.title_changed?          # => true
post.save
post.title_changed?          # => false

Both predicates are generated per attribute, so they exist for every column without being written anywhere.
