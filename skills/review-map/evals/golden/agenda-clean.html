What changed

Projects gain an archived state

A project can now be archived. The migration adds a nullable archived_at, Project#archive! stamps it, and a new controller action exposes that. Archiving is the only thing this change does: nothing reads the column yet, and no list filters on it.

The same commit adds a uniqueness validation on slug, which is independent of archival and is the second thing to judge here. inferred

Citations on this page are plain text: nothing on this branch is pushed to a remote, so there is no revision to link a line to.

Checkpoint A

Should archived projects still appear wherever projects are listed?

Archiving writes archived_at and touches nothing else. Every selectable-project list in the app goes through one query object, and that object scopes on discarded_at — a different column — so an archived project stays in every list it was in before. from unchanged code Whether that is the intended first step or an omission is the thing to decide.
